02

先備能力與三個本課概念

開始前先確認
  • 能使用事件當時的DHCP租約
  • 理解NAT、共享帳號與名稱解析限制
  • 能為每條關聯記有效時間與來源
時間有效性

帳號、IP、主機關聯只在證據涵蓋期間有效。

別混淆：用現在DNS覆蓋歷史；否則會失去可重算的證據界線。

關聯信心

登入、DHCP、資產三種獨立來源可提高信心。

別混淆：只靠反向DNS就指認人。

共享限制

NAT、跳板機、共用帳號會造成多對多；需用「AD、使用者與 IP 關聯教學資料集（去識別）」的欄位與資料列逐項驗證。

別混淆：強迫建立一對一關係；否則會失去可重算的證據界線。

位置、版本與安全 Gate

教材只固定工作目的與驗收證據，不把未核對的子選單、按鈕或欄位畫成真實 UI。

G0／G1

操作邊界

  1. G0 可用去識別樣本反覆練習。
  2. G1 只查詢、檢視與核准匯出。
  3. G2 僅在核准 LAB 建立可清理物件。
  4. 任何外送、正式來源、自動執行、升級或服務變更均須逐項 G3 Gate。

05

跟著做：每一步都有預期與失敗訊號

1

固定事件時間：依「AD、使用者與 IP 關聯教學資料集（去識別）」逐列處理

輸入：四段有效期；使用「AD、使用者與 IP 關聯教學資料集（去識別）」對應欄位

預期：關聯依時間切片，並可依資料列客觀重算

證據：同IP先host-a後host-b

失敗：忽略租約邊界即失敗，立即停止並記錄實際差異

2

建立邊：依「AD、使用者與 IP 關聯教學資料集（去識別）」逐列處理

輸入：帳號-IP-host-source

預期：每條邊有來源與有效期

證據：第一列高於DNS-only

失敗：把DNS-only當確證即失敗

3

標共享：依「AD、使用者與 IP 關聯教學資料集（去識別）」逐列處理

輸入：shared與jump-1

預期：顯示多使用者可能性，並可依資料列客觀重算

證據：負證：shared不能指認個人

失敗：資訊不足標UNKNOWN

4

評信心：依「AD、使用者與 IP 關聯教學資料集（去識別）」逐列處理

輸入：來源數與一致性；使用「AD、使用者與 IP 關聯教學資料集（去識別）」對應欄位

預期：高／中／低附理由，並可依資料列客觀重算

證據：保留衝突與缺口，保留對應資料列與判定依據

失敗：不得將信心當機率捏造

停止條件：環境、角色、版本、影響範圍、回復方式或核准任一項不清楚，就停在觀察與設計。

獨立任務 · 約 25 分鐘

繪製事件當時的身分—IP—資產關聯圖。

限制

  • 所有 IP 僅可使用 RFC 5737 文件位址（192.0.2.0/24、198.51.100.0/24、203.0.113.0/24），不得代入真實位址。
  • 每條邊都要有效起訖與證據來源
  • NAT、共享及UNKNOWN不可消失

必交欄位

  • 事件時間
  • 節點與關聯邊
  • 證據來源
  • 有效期
  • 信心與限制

10

本課專屬排錯

同IP兩主機

最小檢查：查租約起訖

預期：時段不重疊或衝突可見

修正：依事件時間選有效租約

停止／升級：衝突未解時不歸因

只有DNS

最小檢查：查DHCP／登入／EDR

預期：可取得第二來源

修正：降信心並補查

停止／升級：不可指認使用者

共享帳號

最小檢查：查session與端點證據

預期：可縮小但未必唯一

修正：標共享並升級owner

停止／升級：無session即停止個人歸因

教師版與錯項解析

案例答案

以事件當時 DHCP／登入證據關聯 host-a，標示有效時間；不能用目前解析結果覆蓋歷史。

錯項一

現在是 host-b，所以歷史事件一定也是 host-b。

錯項二

IP 可永久代表單一使用者。

完成獨立任務後再展開參考成果
  • 01:00-02:00的192.0.2.44對host-a；之後轉為host-b。
  • shared@jump-1不能唯一歸因自然人。
  • 203.0.113.5只有DNS證據，信心低且主機UNKNOWN。
安全界線

先用 G0／G1 建立證據，再依核准進 G2；任何外送、正式來源、自動執行、升級、重啟或回復都停在 G3 Gate 前。
