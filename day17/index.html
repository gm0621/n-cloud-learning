LESSON 17 · IP LABELS

名稱要更好讀，
也要能追溯來源

你會整理 IP、名稱、範圍、負責人與狀態，檢查 CSV 編碼、重複與衝突，再以 G2 LAB 驗證。

本課目標
  1. 設計不誤導的 IP 名稱
  2. 檢查 CSV schema、編碼與衝突
  3. 分開預覽、匯入、驗證與回復
建議時間：約 70–85 分鐘

本課章節

01 名稱不是事實02 CSV 欄位03 品質檢查04 匯入 Gate05 模擬清單06 實作一07 實作二08 排錯09 完成紀錄

01

名稱幫助閱讀，但不能取代原始 IP

好的名稱

`TC-FIN-ERP-01` 能指出位置、部門、用途與序號，並有負責人和來源。

危險名稱

`駭客主機` 把尚未證實的判斷寫進名稱，容易誤導後續調查。

保留原值

介面可顯示友善名稱，但查詢、匯出與調查紀錄仍應保留原始 IP。

02

CSV 至少要能回答五件事

1IP要映射的原始位址
2Name一致命名、不做定性
3Scope環境、位置或租戶
4Owner／Status負責人與有效狀態

實際必填欄位、欄名與匯入格式必須依指定版本的模板核對；本課格式只作教學。

03

匯入前先做六項靜態檢查

Schema

欄名與欄數

使用核准模板，不自行加減必填欄。

UTF-8

編碼與分隔符

避免中文亂碼、逗號錯欄與隱藏 BOM 行為。

Unique

重複與衝突

同一範圍內一個 IP 不應有兩個現行名稱。

Safe

試算表公式

文字不得以 `= + - @` 等公式起始字元造成風險。

05

模擬 CSV：先找出三個問題

教學模擬 IP 名稱解析 CSV｜不代表真實 N-Cloud 匯入模板
ipnamescopeownerstatus
192.0.2.15TC-BACKUP-01LAB-TCInfraactive
192.0.2.20TC-FIN-ERP-01LAB-TCFinance-ITactive
192.0.2.20Old-ERPLAB-TCunknownactive
192.0.2.31=HYPERLINK(...)LAB-TCunknownactive
192.0.2.99TC-UNKNOWN-99LAB-TCunknownretired
三個問題

`192.0.2.20` 重複且名稱衝突；公式起始字元需隔離；retired 項目不得當現行名稱匯入。

尚未答對

G2 LAB 驗收

匯入後要證明

  1. 只新增預期的三筆。
  2. IP 原值仍可見。
  3. 搜尋與顯示名稱正確。
  4. 重複與 retired 未匯入。
  5. 清理後恢復到操作前狀態。

08

排錯：CSV 成功但名稱不對

中文亂碼

核對 UTF-8、BOM 與產品要求的編碼。

欄位錯位

檢查逗號、引號、換行與模板欄序。

名稱沒更新

確認 scope、覆寫規則、快取與生效時間。

多出非預期項目

停止後續匯入，保存結果並依回復計畫清理。

詳解

「匯入成功」只代表系統接受檔案；仍需核對筆數、範圍、顯示與可回復性。
