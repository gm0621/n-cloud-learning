# N-Cloud 完整學習教材

**公開教材：<https://gm0621.github.io/n-cloud-learning/>**

這是一套以繁體中文製作的自主學習網頁，不以天數趕進度，而以「真正能判讀與調查」為完成目標。每課採用「目的 → 概念 → 案例 → 實作 → 解釋證據 → 完成紀錄」的節奏。

## 完整課程路線

### 階段一：建立全貌

1. N-Cloud 在做什麼
2. 資料如何進入 N-Cloud

### 階段二：看懂四類資料

3. Syslog 欄位與事件
4. Flow 與通聯分析
5. SNMP 與設備健康
6. PM 與服務品質

### 階段三：把資料變成監控

7. 時間範圍與搜尋條件
8. TopN、報表與 Dashboard
9. 門檻、規則與告警

### 階段四：完成真正的調查

10. 故障排查方法
11. 資安事件調查
12. 綜合事件調查

## 已發布

- 第一課：先看懂 N-Cloud 在做什麼
  - Syslog、Flow、SNMP、PM 的角色
  - 「網路很慢」整合案例
  - 三個資料來源判斷練習
- 第二課：資料如何進入 N-Cloud
  - 設備、傳輸、Receiver／Collector、正規化、儲存、搜尋與告警
  - 資料旅程排序實作
  - 三個斷點診斷練習

後續課程會依學習結果逐課製作，不以固定日期切割，也不虛構尚未確認的產品畫面與版本細節。

## 實作路線

每課都有實作，但不會一開始就要求操作正式環境；會先建立判斷力，再逐步進到真實 N-Cloud 操作。

1. **單點判斷**：選擇、配對、排序與欄位辨識。
2. **模擬調查**：使用仿真紀錄完成篩選、TopN、門檻與時間線。
3. **實機操作**：依實際環境與權限在 N-Cloud 找證據。
4. **綜合實作**：從問題回報出發，交叉比對資料並提出可驗證結論。

## 本機開啟

```bash
python3 -m http.server 4173
```

開啟 <http://127.0.0.1:4173/>。
