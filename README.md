- 第一課：先看懂 N-Cloud 在做什麼
  - Syslog、Flow、SNMP、PM 的角色
  - 「網路很慢」整合案例

- 第二課：資料如何進入 N-Cloud

  - 紀錄翻譯與「證據／推測」練習
- 第四課：Flow 與通聯分析

- 第五課：SNMP 與設備健康
  - CPU、記憶體、介面利用率、狀態與錯誤

- 第六課：PM、SLA 與服務品質
  - 延遲、抖動、遺失、回應時間與可用性

- 第七課：時間範圍與搜尋條件
  - 假設、時間窗、分層條件與查不到時的排錯順序
  - 可重現查詢＋G1 唯讀實機練習
- 第八課：TopN、報表與 Dashboard
  - 指標、維度、排行、趨勢與值班閱讀順序

- 第九課：門檻、規則與告警
  - 基準線、持續時間、去重、抑制與恢復
  - 告警風暴修正＋通知安全 Gate
- 第十課：故障排查方法
  - 症狀、範圍、假設與跨資料時間線
  - 「網路很慢」完整排查紀錄
- 第十一課：資安事件調查
  - 帳號、來源、認證與登入後行為
  - 事實／推測／待確認＋可疑登入時間線
- 第十二課：綜合事件調查
  - 跨 Syslog、Flow、SNMP、PM 的證據鏈
  - 90～120 分鐘期末 Capstone 與參考詳解

## 實作路線

每課都有實作，但不會一開始就要求操作正式環境；會先建立判斷力，再逐步進到真實 N-Cloud 操作。

1. **單點判斷**：選擇、配對、排序與欄位辨識。
2. **模擬調查**：使用仿真紀錄完成篩選、TopN、門檻與時間線。
3. **實機操作**：依實際環境與權限在 N-Cloud 找證據。
4. **綜合實作**：從問題回報出發，交叉比對資料並提出可驗證結論。
