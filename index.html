PRACTICE PATH

會有實作，而且會逐步加深

先用安全的模擬資料建立判斷力，確認會看證據後，再進真實 N-Cloud 操作。

01單點判斷

選對資料與欄位

從選擇題、配對與排序開始，說出「為什麼先看它」。

02模擬調查

讀紀錄、找異常

操作仿真資料，完成篩選、TopN、門檻與時間線判讀。

03實機操作

在 N-Cloud 找證據

依環境與權限逐步操作，保留查詢條件、截圖與結論。

04綜合實作

完成事件調查

從使用者回報出發，交叉比對資料並提出可驗證結論。

STARTING ROADMAP

精選起步課程

首頁保留第 1～18 課作為共同起點；完整 9 系列 88 課均已發布，可從完整路線依角色分流。

階段一

建立全貌

先知道每種資料從哪裡來、最後能拿來做什麼。

01可學習

N-Cloud 在做什麼

建立 Syslog、Flow、SNMP、PM 的基本心智模型。

實作：三種情境的資料來源判斷進入第一課 →
02可學習

資料如何進入 N-Cloud

看懂設備、Receiver、正規化、儲存、搜尋與告警的完整旅程。

實作：資料旅程排序＋斷點診斷進入第二課 →
階段二

看懂四類資料

從「知道名稱」進展到能讀欄位、圖表與異常。

03可學習

Syslog 欄位與事件

時間、來源、嚴重度、動作與結果；辨識登入、阻擋和設定異動。

實作：欄位判讀＋證據與推測進入第三課 →
04可學習

Flow 與通聯分析

來源、目的、Port、協定、Bytes 與 Sessions；找出主要流量。

實作：Top Talker＋大流量判讀進入第四課 →
05可學習

SNMP 與設備健康

CPU、記憶體、介面利用率、錯誤與 Port 狀態。

實作：健康焦點＋Counter 差值進入第五課 →
06新課程

PM 與服務品質

可用性、延遲、回應時間與封包遺失，連結使用者感受。

實作：品質指標＋SLA 判定進入第六課 →
階段三

把資料變成監控

學會找資料、呈現重點，並把異常轉成可行動的提醒。

07可學習

時間範圍與搜尋條件

建立假設、選時間窗、組合條件，避免搜尋太廣或太窄。

實作：建立可重現查詢＋實機排錯進入第七課 →
08可學習

TopN、報表與 Dashboard

選對指標與維度，分辨趨勢、排行和單一異常。

實作：設計三格值班 Dashboard進入第八課 →
09可學習

門檻、規則與告警

理解基準線、持續時間、抑制與通知，降低誤報。

實作：修正過度敏感的告警規則進入第九課 →
階段四

完成真正的調查

把事件、流量、設備與服務證據放進同一條時間線。

10可學習

故障排查方法

從症狀、範圍與時間開始，逐步排除網路、設備與服務原因。

實作：完成「網路很慢」調查紀錄進入第十課 →
11可學習

資安事件調查

用登入、阻擋與異常通聯建立時間線，不把單一告警當結論。

實作：重建可疑登入事件時間線進入第十一課 →
12期末實作

綜合事件調查

接收一則使用者回報，自行選資料、找證據、形成結論與建議。

驗收：證據鏈、結論、下一步與反思進入第十二課 →
階段五

進入安全實機操作

先辨識環境與權限，再做唯讀查詢、原始資料核對與可逆 LAB 寫入。

13可學習

LAB 安全、版本與角色權限

辨識環境、版本、角色與工單授權，用 G0～G3 判斷操作邊界。

實作：環境辨識卡＋可回復 LAB 計畫進入第十三課 →
14可學習

系統資訊與設備樹

記錄版本、節點、時區與保存範圍，靠完整路徑與唯一識別分辨設備。

實作：環境摘要＋設備定向紀錄進入第十四課 →
15可學習

事件查詢入門

依絕對時間、設備、對象與結果建立可重現的 G1 唯讀查詢。

實作：VPN 登入事件查詢＋零結果排錯進入第十五課 →
16可學習

RAW DATA 與欄位

比較原始紀錄與正規化欄位，辨認缺欄、時間與解析限制。

實作：欄位映射＋解析問題交接單進入第十六課 →
17可學習

IP 名稱解析與 CSV

檢查命名來源、CSV schema、編碼、重複與公式風險，再做最小 LAB 匯入。

實作：CSV 清理＋三筆可回復匯入進入第十七課 →
18新課程

儲存查詢與欄位版面

把已驗證條件保存成有目的、範圍、版本與清理方式的個人工作區。

實作：個人查詢＋六欄調查版面進入第十八課 →
