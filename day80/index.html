02

先備能力與三個本課概念

開始前先確認
  • 能依設備／影響域設計告警聚合 key，並保留首告、計數與恢復摘要。
  • 能分辨共享出口 NAT 限制、多帳號認證結果、設定變更與服務 timeout 的替代假設。
  • 能區分觀察、假設、驗證與變更 Gate；缺少受控來源或超出核准範圍時停止。
共享出口

多帳號來自同一出口位址不能直接推論為同一人，須結合身分與認證來源。

別混淆：以 IP 當永久身分會造成錯誤封鎖與聚合。

告警降噪

聚合 key 應保留租戶、設備、事件類型及影響域，並記錄首告、計數與恢復。

別混淆：只按訊息文字聚合可能吞掉不同設備事故。

改善對照

第二次演練以返工次數、checkpoint 準時率、回歸覆蓋與證據完整率比較第一次。

別混淆：只比較最後分數無法指出流程是否改善。

05

跟著做：每一步都有預期與失敗訊號

1

組成十二列 VPN 證據時間線

輸入：按 14:00–14:25 排序需求、Auth、Flow、變更、Alert、服務、回放、恢復、檢討。

預期：十二筆各出現一次且 CP0～CP6 完整。

證據：以 REQ-VPN-2、AU／FL／CF／AL／SM／RP／RC／RV ID 為索引。

失敗：漏列、改寫時間或缺 checkpoint 即失敗。

2

建立認證失敗的替代假設表

輸入：比較 AU-101、AU-102、FL-201、AU-103、CF-301、SM-501。

預期：保留 NAT 限制；acct-a 成功反對「全為攻擊」，14:05 變更與 timeout 支持服務／設定問題。

證據：每個假設列支持與反對 ID，不以共享 IP 指認個人。

失敗：一 IP 一人、只看失敗事件或忽略成功紀錄即不通過。

3

驗證聚合 key 的正反案例

輸入：使用 AL-401 同設備 60 筆及 AL-402 另一設備 5 筆。

預期：同設備重複可聚合，另一設備不可併入；首告、計數、影響域均保留。

證據：正例 key 與反例 key 各列輸入 ID 和預期群組。

失敗：把 65 筆合成一組、遺失設備 key 或計數對不上即失敗。

4

核對回放、恢復與改善 checkpoint

輸入：使用 RP-601=3摘要、RC-701成功率恢復、RV-801返工1與準時5/6。

預期：CP5 證明三摘要及恢復；CP6 明列返工1、5/6及與模擬一不同的改善。

證據：回放輸出、恢復摘要及改善分子分母齊全。

失敗：摘要數非3、未保留兩影響域或把5/6寫成全數準時即退件。

停止條件：環境、角色、版本、影響範圍、回復方式或核准任一項不清楚，就停在觀察與設計。

10

本課專屬排錯

VPN 證據時間線少於十二筆、CP0～CP6 不完整，或為配合結論而改動 14:00–14:25 的時間。

最小檢查：以 REQ-VPN-2、AU-101、AU-102、FL-201、AU-103、CF-301、AL-401、AL-402、SM-501、RP-601、RC-701、RV-801 清點唯一 ID，按原始絕對時間映射 checkpoint。

預期：十二筆各出現一次，時間不被改寫；CP0～CP6 均有需求、認證、流量、變更、告警、服務、回放、恢復或檢討證據。

修正：以紀錄 ID 補漏及去重，保留同分鐘不同來源；重新建立 ID→時間→CP 索引，不沿用模擬一的事件或結論填補缺口。

停止／升級：任一 ID／checkpoint 仍缺漏、資料時間需人工改寫，或混入非本次去識別 fixture 資料時，不得進入聚合與改善驗收。

因 AU-101、AU-102 來自共享出口就把兩個帳號指認為同一人或直接定性攻擊。

最小檢查：並列 AU-101、AU-102 的失敗、FL-201 的共享出口限制、AU-103 的 acct-a 成功、CF-301 的 14:05 設定變更與 SM-501 的 timeout 升高，逐假設列支持與反對 ID。

預期：NAT 只表示來源位址不能作永久身分；AU-103 反對「全為攻擊」，CF-301 與 SM-501 支持設定／服務問題作為替代假設。

修正：移除以 IP 指認個人的欄位與結論，改以去識別帳號、認證結果、變更和服務指標分層比較；將攻擊、設定及服務假設都保留證據界線。

停止／升級：缺成功紀錄或變更／服務旁證、必須取得真實個資才能歸因，或仍以共享 IP 執行個人封鎖時，停止結論與任何外部處置。

AL-401 的同設備 60 筆與 AL-402 的另一設備 5 筆被合成 65 筆一組，或回放不是 3 摘要且遺失恢復／改善資料。

最小檢查：檢查聚合 key 是否至少保留租戶、設備、事件類型與影響域；以 AL-401 作同設備正例、AL-402 作不可合併反例，並核對 RP-601=3 摘要、RC-701 成功率恢復、RV-801 返工 1 次及準時 5/6。

預期：60 筆可在其設備／影響域內降噪，5 筆維持另一群組；回放恰有 3 摘要且保留兩影響域、首告、計數與恢復，改善表如實記為 1 次返工及 5/6 準時。

修正：把設備與影響域補回聚合 key，重新回放固定資料並逐群核對首告及計數；補上 RC-701 恢復摘要，將誤寫的 6/6 改回 RV-801 的 5/6。

停止／升級：仍合成 65 筆、摘要數非 3、任一影響域或恢復遺失，或改善數字無分子分母時，聚合規則不得發布。
