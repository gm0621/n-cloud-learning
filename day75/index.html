Tracer bullet

別混淆：從畫面消失不一定代表輪詢、資料或 License 影響已清除。

05

跟著做：每一步都有預期與失敗訊號

1

保存 LAB 建立前零基準

輸入：讀取「基準／LAB 物件 0／計數與時間」。

預期：記錄核准範圍、絕對時間與物件數 0。

證據：基準證據含 Gate、時間、計數與觀察者。

失敗：起始不是 0、範圍不明或已有同名物件時停止。

2

追蹤唯一樣本的接收序號

輸入：使用 SIM-LAB-SRC-01 與 RFC 文件位址範例樣本。

預期：物件數成為 1、接收計數恰增 1，序號可連回唯一來源。

證據：保存前後計數、物件識別與樣本序號。

失敗：多建立物件、計數增量非 1 或序號對不上即失敗。

3

核對名稱有效窗與原值

輸入：比較 sim-edge-a 映射前後欄位及有效時間。

預期：有效窗內顯示 sim-edge-a，窗外仍可重建原值。

證據：名稱證據含原值、新值、起訖與樣本序號。

失敗：覆寫原值、缺時區或把現在名稱套到歷史即不通過。

4

證明查詢命中與零殘留

輸入：使用涵蓋樣本的絕對時間窗及清理列。

預期：查到恰 1 筆後，清理檢查回到 0 物件並記資料影響。

證據：查詢條件、命中 ID、清理後計數與輪詢狀態齊全。

失敗：仍有物件／輪詢、命中不是 1 或無法說明資料殘留時停止。

停止條件：環境、角色、版本、影響範圍、回復方式或核准任一項不清楚，就停在觀察與設計。

本課專屬排錯

建立 SIM-LAB-SRC-01 前，LAB 物件數不是 0，或已存在同名物件而無法建立乾淨基準。

最小檢查：確認核准 LAB 範圍、觀察者、絕對時間與物件計數，並搜尋是否已有 SIM-LAB-SRC-01、殘留輪詢或前次測試資料影響。

預期：建立前基準明確記錄為 0 個測試來源，無同名物件與活動輪詢，且 Gate、時間及觀察者齊全。

修正：不要覆蓋或沿用不明物件；先依核准清理流程移除前次模擬殘留並重取基準。若殘留來源不明，保留證據並交由環境 owner 處理。

停止／升級：範圍未核准、來源歸屬不明、清理不可逆，或重取後仍非 0 時，不得建立新來源。

送出唯一樣本後物件不只 1、接收計數增量不是 +1，或接收／解析／查詢所見的樣本序號對不上。

最小檢查：以 SIM-LAB-SRC-01、同一個 RFC 文件位址範例與唯一樣本序號，比較送出前後物件數及接收計數，並沿接收、解析、名稱、查詢四段核對序號。

預期：物件由 0 變 1、接收計數恰增加 1，四段都引用同一來源與同一樣本序號，沒有第二來源或重送副本。

修正：立即停止傳送，排除重複注入或額外來源；回到 0 基準後只重送一次去識別樣本，逐段記錄第一個序號中斷點，不用新增樣本掩蓋缺口。

停止／升級：無法隔離唯一來源、計數持續增加、序號斷鏈，或需使用真實位址／帳號才能重現時，停止測試並保留斷點證據。

sim-edge-a 被套用到有效窗外的歷史事件、原始識別被覆寫，或查詢命中後清理仍留有物件／輪詢。

最小檢查：核對名稱映射的原值、新值、時區、有效起訖與樣本序號；再用涵蓋該樣本的絕對時間窗確認恰命中 1 筆，並檢查刪除後物件數、輪詢及資料殘留說明。

預期：有效窗內顯示 sim-edge-a 且原值仍可重建，窗外使用歷史正確值；查詢恰 1 筆，清理後物件與輪詢回到基準 0。

修正：恢復不可變的原始識別，補齊帶時區的映射起訖後重查同一序號；依回復點移除映射與測試物件，另記錄既有資料是否保留及其影響。

停止／升級：原值已不可復原、有效時間不明、命中數非 1，或刪除後仍有物件／輪詢且無核准清理方法時，不得宣稱閉環完成。
