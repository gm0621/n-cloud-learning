01

先確定這課要解決什麼

Question核心問題串聯失敗、成功、來源、帳號、設備與設定異動，提出可驗證假設
ArtifactVPN 登入事件時間線不是只看畫面，而是留下可交接成果
Evidence可重現時間線可分辨單一使用者、來源集中、全域認證或設定變更，且保留限制
Boundary不超過證據多次失敗可能是輸入錯誤、服務異常或攻擊；不能只憑次數定性

02

先備能力與三個本課概念

開始前先確認
  • 能區分登入成功與失敗
  • 理解共享出口不能唯一識別使用者
  • 可對齊 VPN、RADIUS／MFA 與變更時間
認證序列

失敗後成功可能是輸入修正、服務恢復或攻擊，須看同窗群體。

別混淆：將失敗次數直接定性暴力破解。

共享出口

同一來源 IP 可代表多名使用者或設備。

別混淆：把 IP 永久綁定單一人。

替代假設

同時保留帳密錯誤、認證服務異常、設定變更與攻擊。

別混淆：只蒐集支持第一直覺的資料。

03

位置、版本與安全 Gate

候選入口｜必須以實機版本與角色核對事件查詢；必要時搭配操作歷程與 Flow

教材只固定工作目的與驗收證據，不把未核對的子選單、按鈕或欄位畫成真實 UI。

G0／G1

操作邊界

  1. G0 可用去識別樣本反覆練習。
  2. G1 只查詢、檢視與核准匯出。
  3. G2 僅在核准 LAB 建立可清理物件。
  4. 任何外送、正式來源、自動執行、升級或服務變更均須逐項 G3 Gate。

05

跟著做：每一步都有預期與失敗訊號

1

排時間線：依「VPN 登入異常教學資料集（去識別）」逐列處理

輸入：四列登入；使用「VPN 登入異常教學資料集（去識別）」對應欄位

預期：依 UTC 排出帳號、來源與結果

證據：包含成功與失敗的正反對照

失敗：漏掉成功事件會造成偏誤

2

做分群：依「VPN 登入異常教學資料集（去識別）」逐列處理

輸入：account、source_ip、peer_failures

預期：分辨單帳號與群體異常

證據：第1、2列支持共享服務問題；第4列支持查變更

失敗：共享 IP 被當成人即失敗

3

檢驗假設：依「VPN 登入異常教學資料集（去識別）」逐列處理

輸入：認證服務、使用者錯誤、攻擊、變更

預期：每假設有支持與反證，並可依資料列客觀重算

證據：change_id chg-17 是待查線索而非根因

失敗：沒有 RADIUS/MFA 資料須標 UNKNOWN

4

提出下一步：依「VPN 登入異常教學資料集（去識別）」逐列處理

輸入：最小唯讀查詢；使用「VPN 登入異常教學資料集（去識別）」對應欄位

預期：先查同窗 RADIUS/MFA 與變更17

證據：保存查詢為0及有值兩種證據

失敗：任何鎖帳或封鎖需另行核准

停止條件：環境、角色、版本、影響範圍、回復方式或核准任一項不清楚，就停在觀察與設計。

07

獨立任務 · 約 25 分鐘

寫出 VPN 登入異常時間線與至少三個可驗證假設。

限制

  • 所有 IP 僅可使用 RFC 5737 文件位址（192.0.2.0/24、198.51.100.0/24、203.0.113.0/24），不得代入真實位址。
  • 不得以來源 IP 唯一識別自然人
  • 處置限唯讀查詢；鎖帳、封鎖或設定變更另走 Gate

必交欄位

  • 時間線
  • 帳號／來源分群
  • 三個假設與反證
  • 待查資料
  • 處置Gate

針對「寫出 VPN 登入異常時間線與至少三個可驗證假設。」，哪個描述達到第一項通過條件？

10

本課專屬排錯

同 IP 事件太多

最小檢查：查 NAT/VPN 出口與工作階段 ID

預期：可標示共享及工作階段

修正：改以帳號與 session 關聯

停止／升級：session 缺失時不做個人歸因

來源時間不一致

最小檢查：查事件與接收時區

預期：可轉成 UTC 並保留原值

修正：校正查詢顯示，不改正式系統時鐘

停止／升級：偏移未知時停止排序因果

查不到 MFA

最小檢查：查資料源健康與保存期

預期：能判斷缺資料或真無事件

修正：標 UNKNOWN 並向 owner 取證

停止／升級：不可用缺失證明未發生

教師版與錯項解析

案例答案

可能是共用認證或服務問題；需對照其他帳號、RADIUS／MFA 與設定變更，不能只定性暴力破解。

錯項一

成功一次證明前 20 次都是攻擊。

錯項二

帳號 user-a 已確定被同一個人控制。

完成獨立任務後再展開參考成果
  • user-a 失敗後成功不單獨證明攻擊。
  • 同出口多帳號失敗支持共用認證／網路問題，仍需 RADIUS/MFA。
  • user-c 與 chg-17 同窗只構成關聯線索，不能宣告因果。
安全界線

先用 G0／G1 建立證據，再依核准進 G2；任何外送、正式來源、自動執行、升級、重啟或回復都停在 G3 Gate 前。
