01

先確定這課要解決什麼

Question核心問題解讀 5145、4656、4663 等事件，回答誰、從哪裡、對哪個檔案做了什麼
Artifact檔案存取證據表不是只看畫面，而是留下可交接成果
Evidence可重現事件 ID、帳號、主機、share、object、access mask 與結果可回到 RAW 核對
Boundary不超過證據單一 Event ID 不一定等於成功存取；需看 Handle、AccessMask 與關聯事件

02

先備能力與三個本課概念

開始前先確認
  • 能以事件時間、Computer與Logon ID串聯
  • 可回查原始 EventData，不只看正規化欄位
  • 知道 NAS 格式未核對時不得套用 Windows Event ID
5145

Windows 5145 記錄網路共用物件存取檢查，含 share、相對目標與要求的存取；單筆不等於檔案已成功修改或刪除。

別混淆：把5145當成成功刪檔證明。

4656

4656 表示要求物件 handle；Microsoft 明示它不表示已執行存取，應搭配後續事件。

別混淆：把取得／要求handle等同內容已更改。

4663

4663 表示對物件嘗試了特定存取權，需核對 ObjectName、AccessMask／AccessList、handle與稽核設定；仍不可外推成NAS通用格式。

別混淆：看到4663就猜操作與業務結果。

G0／G1

  1. G0 可用去識別樣本反覆練習。

05

跟著做：每一步都有預期與失敗訊號

1

辨識來源：依「Windows／NAS 檔案稽核教學資料集（去識別）」逐列處理

輸入：event_id與computer

預期：Windows三種ID與NAS-X分開

證據：負證：NAS-X不是Windows ID

失敗：把NAS-X套Microsoft語意即失敗

2

串聯事件：依「Windows／NAS 檔案稽核教學資料集（去識別）」逐列處理

輸入：time、Logon ID、Handle ID、Object

預期：前三列形成候選鏈，並可依資料列客觀重算

證據：正證0x123與0x88一致

失敗：只按檔名串聯可能誤配

3

解讀存取：依「Windows／NAS 檔案稽核教學資料集（去識別）」逐列處理

輸入：Access欄及RAW

預期：前三列支持讀取；第4列只見5145 DELETE請求

證據：第4列明確標缺少4663

失敗：把DELETE字串宣告成功刪除即失敗

4

寫證據界線：依「Windows／NAS 檔案稽核教學資料集（去識別）」逐列處理

輸入：Microsoft定義與NAS缺口

預期：每列分成已證實、未證實、待查

證據：包含正、負、失敗證據

失敗：RAW缺失時停止具體操作定性

停止條件：環境、角色、版本、影響範圍、回復方式或核准任一項不清楚，就停在觀察與設計。

獨立任務 · 約 25 分鐘

限制

  • 所有 IP 僅可使用 RFC 5737 文件位址（192.0.2.0/24、198.51.100.0/24、203.0.113.0/24），不得代入真實位址。
  • Windows事件必須以Computer、時間、Logon ID、Handle ID及物件交叉核對

必交欄位

  • 來源與事件ID
  • 主體與來源位址

教師版與錯項解析

案例答案

只能證明 Windows 稽核中有 share 存取請求；無法由此證明檔案成功修改，也不能外推 NAS。

錯項一

5145 一定代表檔案已成功刪除。

錯項二

所有 NAS 都會產生相同 Event ID。

完成獨立任務後再展開參考成果
  • 前三列可串成對report.docx的讀取證據鏈：5145共用檢查、4656 handle要求、4663特定存取。
  • 第4列只有5145與DELETE要求，不能證明old.docx已成功刪除。
  • NAS-X的供應商語意未提供，保持UNKNOWN並要求受控文件。
